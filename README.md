# ConcreteFlow

Приложение для менеджера бетонного завода: создание, отправка и ведение заявок на отгрузку бетона.

## Что умеет

- создавать заявку с параметрами клиента, марки, объёма, времени и адреса;
- назначать ответственных по заявке: менеджера, диспетчера и водителя;
- отправлять заявку в Telegram-канал/чат через Bot API;
- отправлять уведомление клиенту в WhatsApp (с SMS-резервом);
- переключать статус заявки: `Новая` → `Подтверждена` → `Выполнена`;
- вести историю действий по заявкам (создание, смена статуса, отправка в Telegram, уведомление клиента, удаление);
- фильтровать текущие заявки и историю по статусу;
- сохранять заявки, историю и Telegram-настройки в `localStorage` браузера.

## Настройка Telegram

1. Создайте Telegram-бота через `@BotFather` и получите `Bot Token`.
2. Добавьте бота в нужный канал или чат.
3. Укажите `Chat ID` (для канала обычно вида `-100...`).
4. В интерфейсе ConcreteFlow заполните `Bot Token` и `Chat ID`, затем нажмите «Сохранить Telegram-настройки».

## Запуск

```bash
python3 -m http.server 4173
```

Откройте: <http://localhost:4173>
